There are a few risks associated with tokenized strategies - beyond the risk of the strategy itself (detailed [here](https://help.lyra.finance/en/articles/9555717-susdebull-strategy)). It is important that users are aware of these risks before depositing to or acquiring a tokenized strategy. Note that this is not necessarily an exhaustive list.
## 
Execution Risks
[](https://docs.derive.xyz/docs/bull-risks#execution-risks)
  * Per the Derive [docs](https://docs.lyra.finance/docs/oracles-1), for each market, there is a set of oracle inputs used for marking assets when computing margin and liquidations. This data is posted onchain for transparency and available via the public REST API. This data is provided by [Block Scholes](https://www.blockscholes.com/).
  * It’s possible that feeds for certain assets (particularly less liquid ones) may have marks that deviate from the true fair value, which can result in suboptimal execution for the strategy vault.


## 
Underlying Collateral Risks
[](https://docs.derive.xyz/docs/bull-risks#underlying-collateral-risks)
  * sUSDe:[documentation](https://www.notion.so/Ethena-FAQs-3ccc1437e13343f8b74c0d005e4f5128?pvs=21) for more details.
  * weETH:[documentation](https://etherfi.gitbook.io/etherfi/ether.fi-whitepaper/risks#smart-contract-risks) for more details.


## 
Bridge Risk
[](https://docs.derive.xyz/docs/bull-risks#bridge-risk)
  * Transferring assets from one network to another carries risks associated with the underlying bridge provider. In this product, we use Socket as the bridge provider. Please review their [documentation](https://docs.socket.tech/introduction) for more details.


## 
Smart Contract Risk
[](https://docs.derive.xyz/docs/bull-risks#smart-contract-risk)
  * Interacting with any smart contract carries the risk of losing access to your funds. The immutable nature of smart contacts makes it difficult and potentially impossible to recover them.
