# How to Deposit HYPE
## 
Introduction
[](https://docs.derive.xyz/docs/how-to-deposit-hype#introduction)
This guide explains how HYPE on HyperCore is deposited to Derive. The process consists of two main steps:
## 
1. Transfer HYPE from HyperCore to HyperEVM
[](https://docs.derive.xyz/docs/how-to-deposit-hype#1-transfer-hype-from-hypercore-to-hyperevm)
→ To complete this step, open the Hyperliquid app and connect your EVM wallet.
1A. Navigate to the Portfolio page and select [EVM-Core Transfer]
[![](https://downloads.intercomcdn.com/i/o/ytse5axf/1839806849/dec951c29947ae6315a1e82c54f7/Step+1A.png?expires=1777057200&signature=22a7a0bc58e87cd882be76b24240b39a338bb8cb6e00549fc27784c58cdbc05a&req=dSgkH8F%2Bm4lbUPMW1HO4zc2Rgy29Q1q%2BtgZve6gAgF82ZesFLcBRZ6q%2BDSRu%0AYcFcWyinzgYOsqzBprI%3D%0A)](https://downloads.intercomcdn.com/i/o/ytse5axf/1839806849/dec951c29947ae6315a1e82c54f7/Step+1A.png?expires=1777057200&signature=22a7a0bc58e87cd882be76b24240b39a338bb8cb6e00549fc27784c58cdbc05a&req=dSgkH8F%2Bm4lbUPMW1HO4zc2Rgy29Q1q%2BtgZve6gAgF82ZesFLcBRZ6q%2BDSRu%0AYcFcWyinzgYOsqzBprI%3D%0A)
1B. Transfer HYPE spot balance from HyperCore to HyperEVM
[![](https://downloads.intercomcdn.com/i/o/ytse5axf/1839807797/a2c9045b56ec2f7b6a4d85540247/Step+1B.png?expires=1777057200&signature=5a7b2bac0646e2962604372bfb5c00598afa4af8a117db4938563ce2079391e6&req=dSgkH8F%2BmoZWXvMW1HO4zZLl%2B%2FBPFRC3ApCloSJyY2YqMFa%2B3d6abizLIUvI%0AjXrCKS%2BrmYjzlICJkSo%3D%0A)](https://downloads.intercomcdn.com/i/o/ytse5axf/1839807797/a2c9045b56ec2f7b6a4d85540247/Step+1B.png?expires=1777057200&signature=5a7b2bac0646e2962604372bfb5c00598afa4af8a117db4938563ce2079391e6&req=dSgkH8F%2BmoZWXvMW1HO4zZLl%2B%2FBPFRC3ApCloSJyY2YqMFa%2B3d6abizLIUvI%0AjXrCKS%2BrmYjzlICJkSo%3D%0A)
## 
2. Deposit HYPE from HyperEVM to Derive
[](https://docs.derive.xyz/docs/how-to-deposit-hype#2-deposit-hype-from-hyperevm-to-derive)
→ To complete this step, open the Derive app and connect the same EVM wallet.
2A. In the main navigation bar select [Deposit]
[![](https://downloads.intercomcdn.com/i/o/ytse5axf/1839811971/fe207b5abfe9cd4d0b9ef8444d5a/Step+2A.png?expires=1777057200&signature=c44b22229631bbfaf2292d405118971c33769493acb61c262210e2f265245cf2&req=dSgkH8F%2FnIhYWPMW1HO4zYdaM1UYcbENpuFNwLCPAXq0P2gtblvfyx%2BlWEOS%0A3owO5G%2BjkopQ%2BVRkSKI%3D%0A)](https://downloads.intercomcdn.com/i/o/ytse5axf/1839811971/fe207b5abfe9cd4d0b9ef8444d5a/Step+2A.png?expires=1777057200&signature=c44b22229631bbfaf2292d405118971c33769493acb61c262210e2f265245cf2&req=dSgkH8F%2FnIhYWPMW1HO4zYdaM1UYcbENpuFNwLCPAXq0P2gtblvfyx%2BlWEOS%0A3owO5G%2BjkopQ%2BVRkSKI%3D%0A)
2B. Deposit HYPE balance from HyperEVM to Derive
[![](https://downloads.intercomcdn.com/i/o/ytse5axf/1839816077/6212d179517704f9f1ec2aa10dda/Step+2B.png?expires=1777057200&signature=e923b56b03bde6f65487150b348fe93a99643a81b482f5f37f577edcc575348d&req=dSgkH8F%2Fm4FYXvMW1HO4zR7OPELi70VcSkZYq2H8meXU%2Ff%2FM7OkAAyOLHiIn%0At5WU0GVKTLs7lUv2x%2Fg%3D%0A)](https://downloads.intercomcdn.com/i/o/ytse5axf/1839816077/6212d179517704f9f1ec2aa10dda/Step+2B.png?expires=1777057200&signature=e923b56b03bde6f65487150b348fe93a99643a81b482f5f37f577edcc575348d&req=dSgkH8F%2Fm4FYXvMW1HO4zR7OPELi70VcSkZYq2H8meXU%2Ff%2FM7OkAAyOLHiIn%0At5WU0GVKTLs7lUv2x%2Fg%3D%0A)
## 
3. (Optional) HYPE Portfolio Margin
[](https://docs.derive.xyz/docs/how-to-deposit-hype#3-optional-hype-portfolio-margin)
3A. Navigate to the Subaccounts page and select [Create subaccount]
